# ICLR 2027 Neighbors

Paste your title and abstract and find the closest of all 43,013 public ICLR 2027 submissions, the topic you fall into, and where it sits on a map of the conference. Everything runs in your browser.

Site: https://leesangoh.github.io/iclr2027-neighbors/

- Data: public OpenReview submissions (active, desk rejected, withdrawn), collected October 20, 2026. ICLR 2026 comparison uses all 19,814 ICLR 2026 submissions.
- Embeddings: bge-small-en-v1.5, stored as 8-bit vectors. Query embedding runs locally with transformers.js.
- Topics: k-means on embeddings, named from author keywords. Map: UMAP.

Not affiliated with ICLR or OpenReview.
